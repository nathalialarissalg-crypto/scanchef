# scanchef 

O ScanChef e um aplicativo mobile desenvolvido para otimizar a gestao de insumos alimenticios e sugerir receitas personalizadas com base nos ingredientes disponiveis, utilizando integracao com Inteligencia Artificial.

---

## Funcionalidades

- Autenticacao de usuarios e gerenciamento de perfil via Firebase.
- Estruturacao e armazenamento de dados em tempo real no Cloud Firestore.
- Interface mobile responsiva focada na experiencia do usuario.
- Integracao com API de Inteligencia Artificial para interpretacao de ingredientes e geracao de receitas.

---

## Tecnologias Utilizadas

- Frontend e UI Mobile: FlutterFlow / Flutter
- Backend e Banco de Dados: Firebase (Authentication e Cloud Firestore)
- Prototipacao e Design: Figma
- Integracoes: Rest API / AI Services

---

## Arquitetura da Aplicacao

[ Aplicacao Mobile ] ---> [ Firebase Auth & Firestore ]
         |
         +---> [ API de IA ] ---> [ Processamento & Retorno de Receita ]
